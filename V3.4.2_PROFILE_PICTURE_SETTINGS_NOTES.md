# FlowMate v3.4.2 — Profile Picture Settings

## Added
- Settings → Preferences now includes a Profile picture section.
- Users can choose a PNG, JPG, or WebP image from their computer.
- The browser center-crops and resizes the image to 256×256 before saving.
- Users can remove their profile picture and fall back to initials.
- Uploaded profile pictures persist through the existing users.avatar_url field in SQLite or Turso.
- Existing HTTPS avatar URLs remain supported.
- Profile photos now render in the top bar, profile dialog, People directory, chat messages, task comments, and existing avatar-enabled task/member surfaces.

## Storage and safety
- Uploaded images are compressed client-side and accepted only as PNG/JPEG/WebP data images.
- Server rejects oversized avatar payloads (>300 KB decoded / >420k data-URL characters).
- No separate file-storage service is required for profile pictures.
