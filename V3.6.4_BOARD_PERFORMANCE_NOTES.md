# FlowMate v3.6.4 — Board Performance

- Replaced per-card/per-column drag listeners with delegated board listeners.
- Uses a lightweight drag preview to reduce repaint cost.
- Disables expensive card hover/transition effects only while dragging.
- Removes smooth scrolling from the board during drag so native auto-scroll stays responsive.
- Moves a dropped card optimistically and saves in the background instead of reloading/re-rendering the entire board.
- Groups tasks by status in one pass when rendering the board.
- Long columns now scroll internally and use content-visibility to reduce off-screen rendering work.
- Tablet/mobile board columns use responsive horizontal scrolling with snap alignment.
- No database schema or API contract changes.
