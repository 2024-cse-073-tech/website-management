# FlowMate v3.2 — AI Project Brief Planner

## Primary workflow

1. Open **Plan project with AI** from Home, `+ New`, command search, or a List's **AI plan** action.
2. Paste a project brief. No manual task breakdown is required.
3. FlowMate sends the brief and the workspace's active people to the server-side AI planner.
4. AI returns a review draft containing:
   - project name and summary
   - main tasks/workstreams
   - a manager/owner for each main task chosen only from active workspace members
   - related subtasks under every main task
   - a subtask assignee, priority, description, acceptance criteria, estimate, and due date when supported by the brief
5. Review before creation:
   - accept/reject every main task
   - accept/reject individual subtasks
   - edit main task text, manager, priority, due date, and estimate
   - edit subtask text, assignee, and priority
   - Accept all / Reject all / Regenerate
6. **Create accepted plan** persists only accepted work into the database.

## AI assignment behavior

The external AI prompt receives only known workspace members. It considers department, role, current presence/status, active task count, and capacity, and is instructed to balance assignments. It cannot assign an invented user ID.

When an external provider key is configured, the generative provider is used. If it is unavailable or not configured, FlowMate explicitly labels the local fallback rather than pretending it used the external model.

## Hierarchy

Accepted plans are stored as real hierarchical tasks:

- Main task (`parent_task_id = NULL`) — its owner is presented as the **Manager**.
- Subtask (`parent_task_id = <main task id>`) — its owner is the **Assignee**.

List view visually indents subtasks and marks AI-created main tasks with a `MAIN` badge.

## Manual workflow retained

Manual Lists and Tasks still work. Existing tasks also have **Add subtask**, so users are not forced to use AI.

## Review safety

AI preview does not create live project tasks. The project/list and accepted hierarchy are only created after the human clicks **Create accepted plan**.
