# FlowMate v3.1 — Auth, Invites & Contextual AI

## Requested changes completed

- Centered sign-in/sign-up UI.
- Password minimum reduced to 8 characters; uppercase, lowercase, and number requirements retained.
- Forgot Password / reset flow visible from sign-in.
- Signup no longer forces team organization creation.
- Three onboarding choices: create workspace, join workspace, or Personal mode.
- Existing-user invitations support username or email.
- Unregistered email addresses can receive/use a shareable invite link after signup.
- Invite links auto-join after sign-in/signup when the invited identity matches.
- Immediate invite acceptance; no extra admin-approval gate after a user accepts.
- Personal mode displays `Personal / Just you` instead of CEO/team wording.
- Contextual AI added to List planning, Task title, Task description, Task comments, Docs draft/continue/summary, Chat draft, plus the global assistant.
- AI keys remain server-side.

## Verification

`npm test` passes 23/23 tests, including new tests for exactly 8-character passwords, Personal mode, pre-registration email invite links, idempotent invite-link joins, and frontend contextual AI entry points.
