# FlowMate v3.5.1 — All Tasks hierarchy fix

- All Tasks now loads every non-rejected, non-archived task across every project in the workspace.
- Removed the previous hard LIMIT 1000 from the workspace task endpoint.
- Fixed task List joins to use each task’s own `list_id`, preventing duplicate/incorrect rows in multi-list projects.
- Backend reconstructs the full Main Task -> Subtask -> Nested Task hierarchy and returns `task_depth`, `task_level`, `root_task_id`, `parent_title`, and `project_name`.
- All Tasks groups rows by project and visibly indents Main/Sub/Nested tasks.
- Added total/main/sub/nested counts and broader search across task, project, assignee, location, and parent title.
- My Tasks still filters to the current user while retaining original hierarchy depth metadata.
