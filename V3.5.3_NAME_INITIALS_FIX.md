# FlowMate v3.5.3 — Name Initials & Greeting Fix

- Avatar fallback initials now always use the first letter of the first name token and the first letter of the last name token.
- Examples: `Subhan Khan` → `SK`, `Subhan Ali Khan` → `SK`, `Muhammad Subhan Ali Khan` → `MK`, single name `Subhan` → `S`.
- Home greeting now shows the user's proper full name instead of a shortened/initial-based value.
- Existing profile-picture behavior remains unchanged: uploaded DP is shown first; initials are only the fallback.
