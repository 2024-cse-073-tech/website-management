# FlowMate v3.6.0

This release adds file-powered project briefs and explicit human review.

- Upload/drag-drop: PDF, DOCX, MD, TXT, RTF, CSV, JSON (5 MB per PDF/DOCX).
- Uploaded text is appended to the brief before AI planning.
- Generated main tasks, subtasks, and nested steps start Pending.
- Each item has Accept, Reject, Regenerate, and Edit controls.
- Bulk Accept all / Reject all remain available.
- Commit accepts only items explicitly marked Accepted.
- Individual regenerate calls the AI only for that selected main task/subtask/nested step.
- Planner body has independent vertical scrolling and a stable action footer.
