# FlowMate v3.5.2 — No Sample Project

- Removed automatic creation of the legacy **Project Management** sample project/list.
- New workspaces stay project-empty until the user creates a project or commits an AI client brief.
- Added safe cleanup for the exact legacy placeholder only when it has **zero tasks, zero Docs, and zero custom views**.
- Existing real projects are never hidden or replaced.
- Projects sidebar now naturally shows **No projects yet** until real user-created projects exist.
