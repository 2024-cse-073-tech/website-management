# FlowMate v3.5.0 — Multi-project persistence and custom Views

- Every accepted client brief remains a separate `projects` row and a separate `task_lists` row.
- The sidebar now has a dedicated Projects section. Selecting a project opens that project's own list/tasks instead of replacing another client's state.
- Organization project API now returns the linked list, Space/Folder location, manager, and task count so the UI can switch projects explicitly.
- Per-list custom views are stored in the new `list_views` table and work with SQLite and Turso.
- `+ View` now creates a named List, Board, Calendar, or Dashboard view, switches to it, remembers it per project, and supports deletion.
- Built-in and custom view selection is remembered per list in browser state; custom view definitions are stored server-side.
- Regression coverage verifies two independent AI client briefs remain selectable and isolated, and verifies custom views stay scoped to the correct project.
